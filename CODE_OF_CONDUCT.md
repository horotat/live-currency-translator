# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the
work. Harassment, personal attacks, and demeaning comments are not welcome.

Report unacceptable behaviour by opening a
[private security advisory](https://github.com/horotat/live-currency-translator/security/advisories/new)
(it is the only private channel on the repo) or by contacting the maintainer
through their GitHub profile. Reports are handled confidentially.
